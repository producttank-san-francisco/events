# Harness patterns

Presented by Wesley Frederick, ProductTank San Francisco organizer.

The common building blocks behind tonight's workflows, without code terms:

- **Text exchange:** every AI tool trades text between a system (the standing instructions), a user (you), and tools (actions the AI can take).
- **Chat history:** the running record of that exchange.
- **Replay:** run the same history again.
- **Fork:** branch a conversation to try a different path.
- **Sub-agents:** hand a smaller task to a separate AI helper.
- **Memory:** notes the AI keeps between sessions.
